Kimi Thinking Prefill
Injects a reasoning_content prefill (partial assistant message) for Kimi/Moonshot models, client-side. Equivalent to the kimi-k3-jb server patch — no server files need to be modified.
Sent as { role: 'assistant', content: '', reasoning_content: <this>, partial: true } at the end of the prompt. The model continues thinking from this text.
Only applies when the current model id contains one of these (e.g. moonshotai/kimi-k3, kimi-k3).
Required for the prefill to work: with thinking disabled the model continues the seeded reasoning_content with reply text instead of reasoning. Sets include_reasoning on requests this extension modifies (server sends thinking.type = 'enabled' for Moonshot, reasoning.exclude = false for OpenRouter).
Preset parity: a trailing assistant prompt starting with <think> in your preset is automatically converted to reasoning_content + partial: true, exactly like the patched addAssistantPrefix. Skipped when JSON schema or tools are active.
